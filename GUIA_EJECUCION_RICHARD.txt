VISION3DAI CONTROL FAMILIAR
GUÍA DE EJECUCIÓN PARA RICHARD
====================================================================

REQUISITOS
====================================================================

- Windows 10 o Windows 11.
- Node.js 22 o superior.
- Navegador moderno.
- PowerShell o CMD.

====================================================================
1. ABRIR EL PROYECTO
====================================================================

Abrir PowerShell.

Ingresar a la carpeta del proyecto

cd CUsersluisfDesktopVISION3DAI-CONTROL-FAMILIAR (Frontend + API)

Comprobar contenido

Get-ChildItem

Debe existir

package.json
.env.example
backend
frontend
docs

====================================================================
2. CREAR ARCHIVO .ENV
====================================================================

Ejecutar

Copy-Item .env.example .env

Abrir .env y revisar

PUERTO=3000
ENTORNO=desarrollo

VISION3D_URL=httplocalhost5000

Modificar VISION3D_URL según la dirección real de VISION3D.

====================================================================
3. CREAR SQLITE
====================================================================

PowerShell bloquea npm.ps1.

Utilizar

npm.cmd run migrar

Esto crea

datosvision3dai.sqlite

====================================================================
4. INICIAR APLICACIÓN
====================================================================

Ejecutar

npm.cmd start

Debe aparecer

VISION3DAI disponible en httplocalhost3000

====================================================================
5. ABRIR EL SISTEMA
====================================================================

Abrir navegador

httplocalhost3000

O desde PowerShell

Start-Process httplocalhost3000

====================================================================
9. INTEGRACIÓN VISION3D
====================================================================

VISION3D NO se ejecuta dentro de este proyecto.

VISION3D envía resultados mediante

POST apianalisisresultados

Ejemplo

{
  idExterno resultado-001,
  perfilId 1,
  ejercicio squat,
  repeticiones 20,
  repeticionesCorrectas 17,
  repeticionesMejorables 3,
  confianzaPromedio 0.92,
  visibilidadLandmarksPromedio 0.88,
  tiempoInferenciaMs 155,
  duracionSegundos 42,
  resultado mejorable,
  modeloVersion vision3d-v1
}
